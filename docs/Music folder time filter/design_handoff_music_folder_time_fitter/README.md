# Handoff: 音楽フォルダー時間フィッター（Music Folder Time Fitter）

## Overview
Windows デスクトップアプリ（WPF 想定）の単一メイン画面 + 設定ダイアログ。指定フォルダー配下の音楽ファイル（FLAC, M4A）をフォルダー単位で再生時間集計し、「所要時間」または「目標時刻」の条件に収まるフォルダーだけを一覧表示するツール。

## About the Design Files
このフォルダー内の `.dc.html` ファイルは **HTML で作成したデザインリファレンス（モックアップ）** です。本番コードとしてそのまま使うものではありません。実装は WPF（XAML + C#）で、このデザインが示すレイアウト・配色・状態・インタラクションを、WPF のパターン（データバインディング、スタイル/テンプレート、コマンド等）で再現してください。

`.dc.html` はブラウザで直接開けるプロトタイプ形式です。ブラウザで開いて見た目・挙動を確認しながら実装の参考にしてください（`Music Folder Time Fitter.dc.html` がエントリーポイント。子コンポーネント `AppScreen.dc.html` を読み込みます）。

## Fidelity
**High-fidelity**: 配色・タイポグラフィ・レイアウト・状態は最終案として確定しています。採用案は「1a（Interフォント版）」です（`Music Folder Time Fitter.dc.html` 内にはもう1案 1b: Segoe UI 版も並記されていますが、実装対象は 1a のみです）。

## Screens / Views

### 1. メイン画面（AppScreen）
単一ウインドウ、縦方向に4ブロック。参照モックのサイズは 1040×720px（実アプリはウインドウリサイズに応じて可変にしてよい）。

**A. タイトルバー**

- 左：アプリ名「音楽フォルダー時間フィッター」13px, 600 weight, 色 `#c9cdd6`
- 右：「設定」ボタン（歯車アイコン + テキスト）。ボーダー1px `#4d525c`、角丸5px、hover背景 `#33373f`。クリックで設定ダイアログを開く。

**B. 入力エリア（画面上部固定）**
背景 `oklch(0.175 0.008 260)` ≈ `#1f2226`、下ボーダーあり、padding 16px 20px、要素間 gap 14px。
1. ルートフォルダー行：ラベル「ルートフォルダー」(11px, 600, `#8a8f99`) + テキストボックス（読み取り専用表示、背景 `#1a1d21`、ボーダー `#3d424a`、角丸5px）+「参照...」ボタン（フォルダー選択ダイアログを開く想定）。
2. モード切替 + 実行ボタン行（横並び、下揃え）：
   - ラジオボタン2択、排他選択：
     - 「所要時間」選択時、分入力欄（数値、例: 90）が有効化。単位「分」表示。
     - 「目標時刻」選択時、時刻入力欄（HH:mm、例: 18:30）が有効化。
     - 非選択側の入力欄は disabled 表示（文字色を薄く）。
   - 選択中のラジオは中心にアクセントカラーのドット、リングもアクセントカラー。
   - 「スキャン開始」ボタン：塗り潰しアクセントカラー背景、文字色は濃いダーク（`oklch(0.14 0.01 260)`）、600 weight、角丸5px。

**C. 結果一覧（可変・スクロール領域）**
テーブル4列、ヘッダーは sticky（スクロール時も表示）。
- 列1「フォルダー名」：左寄せ、相対パス表示。
- 列2「合計時間」：右寄せ、固定幅120px、`HH:mm:ss` 表示、tabular-nums。
- 列3「リリース日」：左寄せ、固定幅110px、`YYYY-MM-DD`。
- 列4：固定幅44px、再生ボタン（円形ではなく角丸方形アイコンボタン、28×28px、▶アイコン、色はアクセントカラー、ボーダー1px `#4d525c`）。クリックまたは行ダブルクリックで AIMP 再生。
- 行の下ボーダー `oklch(0.22 0.008 260)`、hover背景 `oklch(0.2 0.008 260)`。
- 該当0件時：テーブル本体の代わりに中央寄せの空状態メッセージ（例:「条件に一致するフォルダーがありません」）を表示すること（本モックには未実装、実装時に追加）。

**D. ステータスバー（画面下部固定）**
背景 `oklch(0.19 0.008 260)`、上ボーダーあり、padding 8px 20px、フォントサイズ 11.5px、色 `#9a9fa8`。
- 左：「スキャン: N 件」「該当: N 件」（アクセントカラー数字）「除外: N 件（タグ読取失敗）」（警告色オレンジ系数字 `oklch(0.7 0.02 40)`）。
- 右：プログレスバー（幅180px、高さ4px、背景 `#3a3e45`、内側にアクセントカラーの帯がスキャン中は左右にアニメーション、完了時は静止 or 非表示）+ ステータステキスト（例:「スキャン完了」/「スキャン中...」）。

### 2. 設定ダイアログ（モーダルオーバーレイ）
- 背景全体に半透明黒 `rgba(0,0,0,0.55)` オーバーレイ、中央に420px幅のカード。
- カード背景 `oklch(0.19 0.008 260)`、ボーダー `#3a3e45`、角丸8px。
- ヘッダー：タイトル「設定」+ 右上×閉じるボタン。
- 本文：ラベル「AIMP 実行ファイルパス（ポータブル版）」+ 読み取り専用テキストボックス + 「参照...」ボタン（実行ファイル選択ダイアログ）。
- フッター：右寄せで「キャンセル」（アウトラインボタン）と「保存」（アクセントカラー塗り潰しボタン）。

## Interactions & Behavior
- モードラジオはクリックで排他選択、非選択側の数値/時刻入力を disabled 化。
- 「参照...」ボタン群は Windows のフォルダー選択 / ファイル選択ダイアログを開く。
- 「スキャン開始」でバックグラウンドスキャンを実行、ステータスバーのプログレスバーとカウントを更新。スキャン完了後にテーブルを結果で置き換える。
- テーブル行の再生ボタン（または行ダブルクリック）で設定済み AIMP パスを使い、該当フォルダーを AIMP で再生する。
- 「設定」ボタン／×／キャンセル／保存はすべて設定ダイアログの開閉をトグルする（保存時は実際に値を永続化する処理を追加）。
- ホバー状態：ボタン・テーブル行に軽いハイライト（上記色を参照）。

## State Management
- `rootFolderPath: string`
- `mode: "duration" | "targetTime"`
- `durationMinutes: number`
- `targetTime: string (HH:mm)`
- `isScanning: boolean`
- `scannedCount: number`, `matchedCount: number`, `excludedCount: number`
- `folders: { path, durationSeconds, releaseDate }[]`（表示用にフォーマット）
- `isSettingsOpen: boolean`
- `aimpExecutablePath: string`（設定として永続化、例: ユーザー設定ファイルや registry/appsettings）

## Design Tokens

- 背景（最外）: `oklch(0.16 0.01 260)` ≈ `#1a1d21`
- パネル背景: `oklch(0.175–0.19 0.008 260)` ≈ `#1f2226` 〜 `#23262b`
- ボーダー: `oklch(0.27–0.34 0.01 260)` ≈ `#3a3e45` 〜 `#4d525c`
- テキスト（主）: `oklch(0.92 0.004 260)` ≈ `#e4e5e8`
- テキスト（副）: `oklch(0.58–0.75 0.005 260)` ≈ `#8a8f99` 〜 `#a8adb5`
- アクセントカラー: ユーザー選択により可変。デフォルト候補 `#4a9eff`（青）。ユーザーは直近プレビューで `#5ec2a5`（緑）も試している — 実装時にどちらか確認すること。
- 警告色（除外件数）: `oklch(0.7 0.02 40)` ≈ 薄いオレンジ

### タイポグラフィ
- フォント: Inter（400/500/600/700）。日本語表示分は OS 標準の日本語フォント（Yu Gothic UI 等）へのフォールバックを想定。
- サイズ: 見出し/ボタン 13px、本文 13px、ラベル/補助 11–11.5px。
- 数値列（時間・日付）は tabular-nums。

### その他
- 角丸: 5px（入力・ボタン）、8px（ダイアログ・ウインドウ）
- シャドウ: ダイアログに `0 20px 50px rgba(0,0,0,0.5)`
