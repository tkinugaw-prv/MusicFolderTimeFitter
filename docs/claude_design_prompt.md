# Claude Design 依頼プロンプト：音楽フォルダー時間フィッター

以下の仕様に基づき、Windows デスクトップアプリ（WPF）の画面デザイン（モックアップ）を作成してください。
実装は別途 VS Code + Claude Code で行うため、ここでは**画面レイアウトと構成要素の提示**が目的です。
ダークテーマ・実用的なツールらしい落ち着いたデザインを希望します（派手な装飾は不要）。

## アプリ概要

指定フォルダー配下の音楽ファイル（FLAC, M4A）をフォルダー単位で再生時間集計し、
「持ち時間」または「目標時刻」に収まるフォルダーだけを一覧表示するツール。

## 必要な画面要素

### 1. 上部：入力エリア

- **ルートフォルダー選択**：テキストボックス（選択中のパス表示）＋「参照...」ボタン
- **時間指定モード切替**：ラジオボタン等で2モードを排他選択
  - モードA「所要時間」：分単位の数値入力（または `HH:mm` 形式）
  - モードB「目標時刻」：時刻入力（時:分）
- **実行ボタン**：「検索」「スキャン開始」等

### 2. 中央：結果一覧（メインコンテンツ）

テーブル形式、以下の3列：

| フォルダー名（相対パス表示） | 合計時間（HH:mm:ss） | リリース日 |
|---|---|---|

- 各行に「AIMPで再生」ボタン（または行ダブルクリックで再生、の想定でアイコン程度でも可）
- 該当フォルダーが0件のときの空状態表示も考慮

### 3. 下部：ステータスバー

- スキャン件数、除外件数（タグ読み取り失敗等）などの簡易ステータス表示
- スキャン中はプログレスインジケーター

### 4. 設定（別画面 or ダイアログでも可）

- AIMP 実行ファイルパスの指定欄（ポータブル版利用前提、テキストボックス＋参照ボタン）

## デザイン方針

- ツール系デスクトップアプリらしい情報密度と実用性を重視（装飾よりも一覧性・可読性優先）
- 入力エリアは常に上部固定、結果一覧はスクロール可能な領域として広く確保
- 1画面構成のシンプルなワイヤーフレーム〜モックアップで十分（複数バリエーション不要）
